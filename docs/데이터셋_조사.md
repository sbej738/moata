# 택시 동승 매칭 예측용 데이터셋 조사

Nov 5, 2026 · @주현

합승 제안의 수락·거절이 개인 단위로 기록된 공개 데이터는 국내에 없다. 수락 확률은 해외 건별 기록으로, 수요 규모는 국내 집계 데이터로 맞추는 조합을 추천한다.

## 수락 확률용 데이터 (해외, 건별 기록)

뉴욕 데이터가 호출 시각이 정확해 가장 적합하다. 합승 의향을 밝힌 사람 중 실제로 매칭된 비율을 시간대·거리·지역별로 학습하면 매칭 성사 확률 모델로 쓸 수 있다.

| 데이터셋 | 쓸 만한 항목 | 한계 |
| --- | --- | --- |
| [뉴욕시 TLC 고용량 FHV 운행 기록](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page) (Uber·Lyft 등) | 호출 시각과 실제 탑승 시각, 출발·도착 구역, 거리, 요금, `shared_request_flag`(합승 동의 여부, 매칭과 무관), `shared_match_flag`(실제로 다른 승객과 같이 탔는지) ([데이터 사전](https://www.nyc.gov/assets/tlc/downloads/pdf/data_dictionary_trip_records_hvfhs.pdf)) | "제안을 거절했다"는 기록은 없고 "합승 의향 → 실제 합승 성사"까지만 있다. 위치는 구역 단위 |
| [시카고 TNP(라이드헤일링) 운행 기록](https://catalog.data.gov/dataset/transportation-network-providers-trips-2023-2024) | 승객의 합승 선택 여부, 실제 합승 성사 여부, 시작·종료 시각, 출발·도착 인구조사 구역, 거리, 요금 | 시각은 15분 단위, 요금은 2.5달러 단위로 반올림. 시카고 합승 연구는 [2019년 1\~9월 데이터](https://ar5iv.labs.arxiv.org/html/2303.03574)를 사용 |

합승 이용 비율은 시기별로 차이가 클 수 있으니, 내려받기 전에 기간별 비율을 먼저 확인한다.

## 수요 예측용 데이터 (국내, 집계)

춘천 택시 호출·승하차 데이터는 공개된 것이 없다. 국토부 통행량으로 춘천 도로별 택시 밀도는 볼 수 있지만, 언제 어디서 호출이 오는지는 알 수 없다.

| 데이터셋 | 내용 |
| --- | --- |
| [인천광역시 택시 운행 통계 조회 서비스](https://www.data.go.kr/data/15113195/openapi.do) | 택시 운행 실적, 자치구별 이동 패턴(OD) 상위 50, 승차 집중 지역 상위 50 (JSON API) |
| [서울특별시 일자별 택시 OD 유형별 상위 10개소](https://www.data.go.kr/biz/dcat/metadata/15135325.do) | 행정동 단위 단거리 이용 수, 심야시간 이용 수 (CSV) |
| [국토교통부 전국 노드링크별 평균택시통행량](https://www.data.go.kr/dcat/metadata/15069016) | 도로 구간별 연간 일평균 택시 통행량. 전국 단위라 춘천도 포함 |
| [경기도 용인시 용인앱택시 운행현황](https://www.data.go.kr/biz/dcat/metadata/15125676.do) | 읍·면·동별 월간 호출 건수, 탑승 건수, 도착 건수. 호출 대비 탑승 비율을 볼 수 있음 |

## 활용 방법

해외 실제 기록으로 패턴을 배우고, 국내 통계로 규모를 맞춘 뒤, 춘천용 가상 데이터로 검증한다.

1. **뉴욕 데이터로 모델 구조 학습** — 시간대·요일별 수요 패턴과 합승 성사에 영향을 주는 요인(거리, 시간대, 대기 시간)을 뽑는다.
2. **국내 데이터로 규모 맞추기** — 서울·인천의 심야 이용 비율, 용인의 호출 대비 탑승 비율로 춘천에 맞는 수요 크기를 정한다.
3. **춘천용 가상 데이터 생성** — 강원대 정문, 한림대, 남춘천역 같은 거점을 중심으로 1\~2번의 패턴을 적용해 가상 이용 기록을 만든다.
4. **발표에서 출처를 분명히** — "뉴욕 실제 합승 기록으로 학습하고, 국내 통계로 춘천 규모에 맞춘 가상 데이터로 검증했다"고 밝힌다.

해커톤 주최 측 제공 데이터가 있는지도 확인한다. 춘천시 AI정책추진단이 공공데이터를 관리하고 있어 택시 관련 데이터를 요청해 볼 수 있다.
